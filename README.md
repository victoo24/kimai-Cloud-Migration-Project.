Kimai Cloud Migration Project

Project Overview

This project focuses on deploying the Kimai time-tracking application on AWS Cloud.

Technologies Used

- AWS EC2
- Docker
- Terraform
- Jenkins
- AWS CloudWatch
- Grafana
- MariaDB

Project Description

The project demonstrates cloud infrastructure setup, containerization, automated deployment, and application monitoring using AWS services and DevOps tools.
